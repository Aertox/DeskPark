# 虚拟角色库

把角色图片放在这个目录，并在 `manifest.json` 中登记，刷新页面后即可在「设置 → 形象 → 虚拟角色」中选择。
联机时其他玩家也会看到你选的角色（形象 id 为 `vc:<id>`）。

## 图片要求

- **格式**：PNG（推荐，背景透明）；也支持 WebP、GIF、SVG。
- **画布**：正方形，**按原始像素尺寸导出、不要放大**，推荐 **64×64**（32×32 / 48×48 / 96×96 / 128×128 也可）。
  显示时会用最近邻方式放大，像素边缘保持锐利。
- **构图**：半身或全身均可。头像框是圆角方形，显示尺寸约 40–64 像素；角色水平居中，头部放在画面上半部分，四周留 1–2 像素边距。
- **不要抗锯齿**：边缘不要半透明羽化，避免放大后发糊。
- **文件名**：小写英文 / 拼音、数字和短横线，例如 `jian-ke.png`。

## manifest.json

```json
{
  "version": 1,
  "characters": [
    { "id": "jian-ke", "name": "剑客", "file": "jian-ke.png", "group": "修仙", "bg": "#cfe6dc" }
  ]
}
```

| 字段    | 必填 | 说明                                      |
| ------- | ---- | ----------------------------------------- |
| `id`    | 是   | 唯一标识：小写字母、数字、短横线，最长 40 |
| `name`  | 是   | 中文名，显示在选择面板上                  |
| `file`  | 是   | 本目录下的图片文件名                      |
| `group` | 否   | 分组名，例如「赛博朋克」「修仙」「动漫」  |
| `bg`    | 否   | 头像底色，例如 `#cfe6dc`；不填则为浅灰蓝  |

也可以直接交一张精灵图（每格大小一致，例如 64×64），附上每格对应的名字，由开发者切分登记。
