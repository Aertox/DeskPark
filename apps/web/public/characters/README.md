# 虚拟角色库

在「设置 → 形象」中切换到 **虚拟形象** 后，牌桌上所有人（包括电脑）都以**全身像素立绘**显示
（无边框、透明背景、循环播放待机动作）。这是每位玩家自己的显示偏好，不影响别人。

角色库里有两类全身像：

- **头像全身像**：与 22 个像素头像一一对应（`avatar` 字段为头像 id）。选了某个像素头像的玩家，在虚拟形象模式下就显示为它的全身像。
- **特别角色**：没有 `avatar` 字段，只能在虚拟形象模式下额外选择（形象 id 为 `vc:<id>`）；在像素头像模式下，从第 1 帧裁出头部作为圆形头像。

## 精灵图

- **格式**：PNG，背景透明。
- **排列**：所有帧等宽等高，从左到右横向排成一行。例如 16 帧 × 48×96 → 整图 768×96。
- **尺寸**：按原始像素导出、不要放大。推荐单帧 **48×96**（人物约占中间 30 像素宽，脚底贴近底边，留 1–2 像素）。
- **动作**：待机循环，首尾帧能无缝衔接；幅度宜小（呼吸起伏 1 像素、衣带发丝摆动 1–2 像素、偶尔眨眼）。
- **不要抗锯齿**：边缘不要半透明羽化，显示时按最近邻放大。
- **文件名**：小写英文 / 拼音、数字和短横线，例如 `yunshang.png`。

## manifest.json

```json
{
  "version": 2,
  "characters": [
    {
      "id": "yunshang",
      "name": "云裳",
      "group": "修仙",
      "file": "yunshang.png",
      "frame": [48, 96],
      "frames": 16,
      "fps": 8,
      "face": [14, 1, 20],
      "bg": "#dfe8e4"
    }
  ]
}
```

| 字段     | 必填 | 说明                                                       |
| -------- | ---- | ---------------------------------------------------------- |
| `id`     | 是   | 唯一标识：小写字母、数字、短横线，最长 40                  |
| `name`   | 是   | 中文名，显示在选择面板上                                   |
| `file`   | 是   | 本目录下的精灵图文件名                                     |
| `frame`  | 是   | 单帧宽高 `[宽, 高]`                                        |
| `frames` | 否   | 帧数，默认 1（静止）                                       |
| `fps`    | 否   | 每秒帧数，默认 6                                           |
| `face`   | 否   | 小头像裁切区域：第 1 帧中的正方形 `[x, y, 边长]`，默认顶部 |
| `group`  | 否   | 分组名，例如「修仙」「赛博朋克」                           |
| `bg`     | 否   | 小头像的底色                                               |
| `avatar` | 否   | 对应的像素头像 id（填写后即为该头像的全身像）              |

## 源文件

内置的 30 个全身像由 `tools/pixel-art/` 下的脚本绘制（Python 3，无第三方依赖），`manifest.json` 也由脚本生成：

```bash
python3 tools/pixel-art/build.py                         # 重新生成全部精灵图与 manifest
python3 tools/pixel-art/build.py --only baihu --preview  # 只画一个，并在当前目录输出放大预览
```

- `kit.py`：统一的头身比例、五官、呼吸 / 眨眼 / 摆动节奏
- `chars/<id>.py`：每个角色一个文件，导出 `META` 与 `frame(t)`
- 新增角色：在 `chars/` 下新建文件，并把模块名加入 `build.py` 的 `AVATAR_FIGURES`（头像全身像）或 `EXTRAS`（特别角色）

手绘的角色也可以直接放进本目录，在 `manifest.json` 中登记即可（重新运行 build.py 会覆盖 manifest，届时把条目加到脚本里）。
