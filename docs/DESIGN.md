# 设计规范

## 原则

1. **安静的界面，突出的牌**：界面元素低饱和、半透明、留白充足，视觉焦点永远在牌与当前行动者上。
2. **一致**：所有尺寸、颜色、圆角、阴影都来自设计令牌（`apps/web/src/styles/tokens.css`），不写魔法值。
3. **克制的动效**：只在信息发生变化时运动（发牌、出牌、轮到你、结算），时长 200–450ms，使用 ease-out 曲线；尊重系统「减少动态效果」设置。
4. **触屏优先**：可点击区域 ≥ 32px，手牌支持拖动多选，横屏手机是一等公民。

## 色彩

| 令牌                            | 用途                   | 浅色                              |
| ------------------------------- | ---------------------- | --------------------------------- |
| `--paper`                       | 大厅背景（暖白纸感）   | `#f4f1ea`                         |
| `--surface`                     | 卡片、面板             | `#fffdf9`                         |
| `--ink` / `--ink-2` / `--ink-3` | 正文 / 次要 / 辅助文字 | `#1c1d1f` / `#5d6166` / `#979ba1` |
| `--accent`                      | 主操作（墨绿）         | `#1f5c4f`                         |
| `--gold`                        | 胜利、地主、强调       | `#b48a4e`                         |
| `--card-red` / `--card-black`   | 花色                   | `#c4352b` / `#1e2126`             |

牌桌桌布提供四种主题（墨绿、黛蓝、酒红、石墨），由 `--felt-1/2/3` 三段径向渐变 + 细噪点纹理 + 内框线构成。牌桌上的强调色统一为香槟金 `--felt-accent`。
大厅支持深色模式（跟随系统或手动切换）。

## 字体

- 界面：系统字体栈（苹方 / Segoe UI / Noto Sans SC），零下载、各平台原生。
- 标题与品牌：宋体系衬线字体（Songti SC / Noto Serif SC），营造「苑」的雅致感。
- 牌面点数：无衬线粗体、紧凑字距；J/Q/K 中央使用西文衬线字母。
- 数字使用等宽数字（`tabular-nums`），避免筹码跳动。

## 卡面

```
┌──────────┐
│ K        │  左上角：点数 + 花色（重叠时唯一可见的部分，必须清晰）
│ ♠        │
│     ┌───┐│
│     │ K ││  右下：数字牌为大花色；J/Q/K 为淡色底块 + 衬线字母
│     │ ♠ ││  大小王：竖排「大王 / 小王」+ 王冠
│     └───┘│
└──────────┘
```

- 宽高比 1 : 1.4，圆角为宽度的 8.5%，尺寸由 `--cw` 随视口自适应（`clamp` + `vw/vh`）。
- 花色使用自绘 SVG，避免 Unicode 花色在部分手机上被渲染为 emoji。
- 牌背：桌布同色系的菱格纹 + 金色「苑」字徽记。
- 万能牌（掼蛋红桃级牌）：右上角金色「配」字圆标。
- 四色牌模式：方块蓝、梅花绿（德州推荐开启）。

## 布局

- 牌桌采用网格：上方信息条、左右（及上方）对手、中央出牌区、下方自己的操作栏与手牌。
- 对手在出牌顺序上的「下家」位于右侧（斗地主/掼蛋惯例）；德州按顺时针排列在椭圆桌边。
- 掼蛋 27 张手牌按点数纵向叠放，节省横向空间。
- 断点：矮屏（≤ 500px 高，横屏手机）时信息条移入顶栏、元素收紧；竖屏手机放大卡牌并提示横屏。
